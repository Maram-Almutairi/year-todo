# قائمة المهام لهذه السنة · My To‑Do List for This Year

A cozy yearly planner: monthly goals, daily quests with XP and streaks, a rain‑soaked sky, and a little knight kitten.

- Arabic / English
- Everything is saved in your own browser (localStorage), with no account or server
- Theme music from YouTube, plus your own YouTube or Spotify links

Open the live site, or run it locally with `start.bat` (Windows) or `node serve.mjs`.
